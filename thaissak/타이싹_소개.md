# 🌱 타이싹 — 싹트는 나의 태국어 회화

3년 전 태국에서 보낸 1년의 기억을 다시 꺼내, 여행과 생활에서 바로 써먹을 수 있는 태국어 회화를 익히기 위해 만든 개인용 학습 웹앱입니다. 마이링고(문장) → 말싹(단어)에 이어 세 번째로 완성한 "~싹" 시리즈 앱이에요.

## 무엇을 할 수 있나요

- **AI가 태국어를 채워줘요**: 한국어로 "이거 얼마예요?"라고 입력하면, Claude API가 태국어 문자·로마자 발음(성조 포함)·예문까지 한 번에 만들어줘요.
- **AI가 추천도 해줘요**: 카테고리(음식/교통/쇼핑 등)만 고르면, 그 상황에서 실제로 쓸 만한 표현 5개를 골라 보여줘요. 체크박스로 원하는 것만 골라 담으면 끝.
- **문장에서 단어만 뽑아 학습**: 통째로 외우기 부담스러운 문장은, 그 안의 핵심 단어만 AI가 추출해서 "기초단어" 카테고리로 따로 모을 수 있어요.
- **플래시카드로 복습**: 태국어 문자와 로마자를 먼저 보고, 탭하면 뜻과 예문이 드러나요. "기억났어요 / 다시 볼게요"로 직접 채점하고, 3번 연속 맞히면 암기 완료 처리돼요.
- **성조를 놓치지 않게 이중 표기**: 태국어 문자만으론 처음엔 읽기 어려우니, Paiboon식 로마자+성조 기호를 함께 저장해요.
- **어디서든 이어서**: Supabase에 저장돼서 폰이든 PC든 같은 표현 목록을 볼 수 있고, 홈 화면에 설치해서 앱처럼 쓸 수 있어요(PWA).

## 말싹과 비교하면 뭐가 다른가요

같은 파이프라인(요건서 → 코드 → Supabase → Netlify → PWA)으로 만들었지만, 두 앱은 태생부터 목표가 달라요.

| 구분 | 말싹 (Mssak) | 타이싹 (Thaissak) |
|---|---|---|
| 학습 언어/대상 | 영어 단어 | 태국어 회화 표현 |
| 데이터 채우는 방식 | **직접 수동 입력만** (v1에 AI 제외) | **AI 자동채움을 v1부터 포함** |
| AI 활용 범위 | 없음 | 문장 채우기 + 추천 받기 + 단어 추출, 3가지 |
| 만든 방식 | 마이링고 파이프라인을 **혼자 재현** | 검증된 파이프라인을 그대로 **적용 + 확장** |
| 성조/발음 표기 | 해당 없음 (영어는 스펠링이 곧 발음 단서) | **태국어 문자 + 로마자 성조 표기 이중 저장** |
| 복습 방식 | 플래시카드 (자가 채점) | 플래시카드 (자가 채점) — 동일 |
| 카테고리 | 자유 카테고리 | 자유 카테고리 + **삭제 불가 고정 카테고리("기초단어")** |
| 경어/문체 설정 | 해당 없음 | **크랍/카 선택 가능** (설정 탭) |
| AI 비용 | 없음 | Claude API 종량제 (본인 키, 호출당 1원 미만 수준) |

**한 줄로 요약하면**: 말싹은 "AI 없이도 파이프라인을 혼자 완주할 수 있는지" 확인하는 앱이었고, 타이싹은 "그 파이프라인 위에 AI를 얹었을 때 얼마나 더 빨리, 더 정확하게 배울 수 있는지" 시험한 앱이에요. 성조 언어라는 태국어의 특성이 AI를 v1부터 들이는 근거가 됐어요.

## 기술 스택

단일 HTML 파일 · Supabase(Seoul, mylingo 프로젝트에 `thai_expressions` 테이블 추가) · Netlify(Public 배포) · Claude API(Haiku 모델, 브라우저 직접 호출) · ElevenLabs(선택적 TTS) · PWA(manifest.json)

## 앞으로 해보고 싶은 것 (향후 계획)

- 태국어 → 한국어 뜻 채움 (반대 방향 AI 지원)
- 로마자 표시 켜기/끄기 옵션
- 여러 표현 일괄 붙여넣기로 추가
